# Utopia-Order-
一个用作量化评分以方便人际管理的html集合，内设联系时间提醒等多项目

An html collection used for quantitative scoring to facilitate interpersonal management, featuring multiple items such as contact time reminders

index.html:
主页，可增删联系人，更改联系人部分信息，查询并筛选联系人，导入和导出数据，设有scoring.html的入口。导入时如果有重复联系人会提醒是否覆盖，判读时依据id+姓名，每个人都有自己的独特id，所以不用担心重名

scoring.html:
用于编辑联系人具体分值和评分理由等，内设adjust the parameters.html入口，即调整参数的页面超链接

adjust the parameters.html:
用于增加删减评分项目，调整环境赋分参数和增删环境
目前作者设置了四个环境，按照普通人2分为基准计算，配置的四个环境的得分系数，不推荐轻易改动。下面是三层次评分准入门槛


**外围层**

定义：信息交换层。双方有基本的了解与互动，主要功能是维持弱连接，获取多样性信息。

准入条件：量化评分总分 ≥ 20分

投入原则：低成本维护，定期刷新联系方式或简单问候即可

退出机制：连续两个评估周期评分低于20分，自动降级至“待观察”状态


**中间层**

定义：资源互助层。双方在特定领域有可交换的专业价值，能够实现实质性合作或资源置换。

准入条件：量化评分总分 ≥ 35分 且 专业领域贡献值 ≥ 3分

投入原则：中等投入，定期深度交流，保持专业领域的协同

退出机制：评分降至35分以下，或专业领域贡献值持续低于2分


**核心层**

定义：信任共同体层。双方经历过多轮利益与非利益考验，具备高度的互信与互惠意识，能够在重大决策或危机时刻互相依靠。

准入条件：量化评分总分 ≥ 45分 且 专业领域贡献值 ≥ 4分 且 至少通过一次压力测试

投入原则：高投入，包括时间、情感、资源，甚至承担一定风险

退出机制：压力测试失败，或连续两个周期评分跌破45分
